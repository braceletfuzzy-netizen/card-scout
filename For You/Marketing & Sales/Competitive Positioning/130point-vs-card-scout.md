# Competitive Positioning: 130Point vs Card Scout

## The Core Difference: Push vs Pull

You discovered this while exploring 130point.com: **the difference is PUSH alerts (us) vs PULL search (them).**

---

## 🎯 The Difference In One Sentence

**130Point = You go TO them (pull, manual)**
**Card Scout = They come TO you (push, automated)**

Same data, different delivery.

## 📊 Detailed Comparison

### 130Point.com (Pull — Manual Search)

```
YOU → open browser → go to site → search
→ scroll results → manually compare prices
→ check if it's a deal → buy or don't

TIME: 15-30 minutes per search
FREQUENCY: When YOU remember to do it
EFFORT: High (manual work)
COST: Free (with ads)
```

### Card Scout (Push — Automated Alerts)

```
YOU → set up watchlist ONCE → forget about it
Discord alerts appear when deals happen

TIME: 30 seconds to review alerts
FREQUENCY: Daily (or 3x/week) automatically
EFFORT: Zero (automated)
COST: $5-50/month
```
